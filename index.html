Fake10 for XFCE
"A faithful Windows 10 theme"
What's so different about Fake10 compared to similar themes?:
• Made from scratch (for better & for worse), raw CSS, easily modifiable
• Abides by the Windows 10 art style as much as possible (no Fluent icons, no pre-10 icons*)
• Doesn't show any branding by default (for any Microsoft software)
• Extremely high attention to detail and accuracy
• Extremely simple accent color customization
• Contains auto-installer shell script
• Contains both light and dark modes
• Contains brand new Win10-style icon recreations
• Contains resizable Windows 10 cursors (and an extra inverted cursor theme)
• Contains multiple start button icons to choose from
• Contains multiple Plymouth boot screens with LUKS support
• Supports the XFCE shade and stick buttons
• Supports Qubes OS and Qubes window coloring

*except for notepad

PLEASE NOTE: If you're aiming for an accurate Windows 10-like experience, run the installer or complete the manual installation guide! Installing the theme correctly makes it way more satisfying, as it was designed to complement certain setting changes.

Aside from that, Fake10 is a fantastic choice for minimal XFCE environments- with it being designed specifically for Arch Linux and Qubes OS. Heavier distributions should work fine, but they contain a lot of bundled programs which Fake10 might not support well. Be wary. Otherwise, try it out!
